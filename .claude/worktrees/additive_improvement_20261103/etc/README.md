# Local Archive

This folder holds non-system artifacts moved out of the repo root to keep the active simulation codebase easier to navigate.

- `archive_outputs/`: historical root-level CSV, Markdown, and JSON experiment outputs
- `archive_docs/`: one-off thesis/supporting documents and conversion helpers
- `external/`: archived backup material and external reference code
- `tmp/`: temporary YAML profiles and similar scratch files

Core code, configs, tests, live telemetry, and the main `results/` tree remain at repo root.
